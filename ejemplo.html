Ejemplo práctico · HTML5 semántico

Una página HTML completa y bien estructurada.

Este ejemplo reúne las etiquetas más importantes en un solo documento: encabezado, navegación, contenido principal, secciones, artículos, listas, tabla, formulario, elementos interactivos y pie de página.

En este ejemplo encontrarás:
  • <header>, <nav>, <main>
  • <section>, <article>, <aside>
  • listas, enlaces, citas y detalles
  • tabla accesible
  • formulario con etiquetas
  • <footer>

Estructura semántica

Cada bloque usa una etiqueta según el significado del contenido y no solamente por su apariencia.

¿Por qué usar HTML semántico?

Ayuda al navegador, a los motores de búsqueda y a las tecnologías de asistencia a comprender qué función cumple cada parte de la página.

Una estructura clara hace que el contenido sea más fácil de mantener, navegar y comprender.

Ventajas principales

  • Mejora la accesibilidad.
  • Facilita el SEO.
  • Hace el código más legible.

Artículo independiente

Un <article> representa contenido que podría tener sentido por sí mismo, como una noticia, una publicación o una entrada de blog.

HTML define la estructura, mientras que CSS se encarga de la presentación visual.

Dato relacionado

El elemento <aside> contiene información complementaria al contenido principal.

Ver recomendación

Evita usar <div> para todo. Primero revisa si existe una etiqueta semántica que represente mejor el contenido.

Tarjetas de contenido

Un mismo documento puede combinar encabezados, párrafos, enlaces y otros elementos.

Enlaces

Los enlaces se crean con <a> y permiten conectar páginas o recursos.

Esqueleto del documento

Esta es la estructura base que deberías reconocer en cualquier página HTML moderna.

Código HTMLestructura-base.html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi página</title>
  </head>
  <body>
    <header>...</header>
    <nav>...</nav>
    <main>
      <section>
        <article>...</article>
      </section>
    </main>
    <footer>...</footer>
  </body>
</html>
